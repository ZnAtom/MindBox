# 8段真实视频处理实测报告

日期：2026-10-16。目标：无需训练，先从用户视频找到物品并给出可理解的大类、名称候选和截图。样本约40秒，全部为1920×1080并带1条音轨。原文件未覆盖。

## 1. 交付与结论

两轮均完成8/8段视频处理，真实调用学校AI，没有使用模拟识别结果。基本闭环可用：选帧、框定、裁剪、饮品/食品识别、描述和证据引用。本轮不具备可靠自动库存增删能力；品牌、背面包装归属和复杂动作仍有明显错误。

- `code/backend/var/runs/crop-rank-check/report.html`：额外仅对v8测试局部清晰度排序，未覆盖替换两轮结果。

## 3. 两轮结果

识别阶段仅遍历视频，不读取人工答案。首轮8段输出完成后才阅读`data/ans.md`进行核对；第二轮属于在这些开发样本上的改进，不能再把它称为独立盲测。没有逐帧框和完整实例标注，不给出虚构的mAP、召回率或SKU准确率。

| 视频 | 首轮观察 | 第二轮观察与仍有的问题 |
| --- | --- | --- |
| v1 | 东方树叶茉莉花茶，裁剪中品牌/品类文字可见 | 识别为瓶装饮品，提示保守后具体品牌留空；取出候选窗约0.001–2.199秒 |
| v2 | 饮品、糖果、小面筋、鸡胸肉四类候选 | 仍得到四类，饮品候选带东方树叶/茉莉花茶；输出取出饮品和放入三包食品候选窗。糖果品牌读法仍不稳定 |
| v3 | 三个食品候选，另把透明抽屉误当容器物品 | 抽屉误检消失；保留鸡胸肉及两个零食候选，但两个候选混入同一粉色包装，白色包装归属错误，未可靠区分三包食品 |
| v4 | 鸡胸肉、食品、小面筋 | 保留三候选；被遮挡糖果只识别为包装食品，框为partial；动作只报拿起放回，未正确复原放入过程 |
| v5 | 糖果、小面筋、鸡胸肉 | 三个食品候选，大类可用；两项crop混入多个包装，具体名称更保守；不能据此说截图已精准分离 |
| v6 | 六个候选，鸡胸肉重复、背面与正面未关联 | 降为四候选：包装食品、鸡胸肉、QQ糖、辣条；仍比人工三件多一个，背面到正面的身份关联未解决，只输出一个放入事件 |
| v7 | 鸡胸肉、辣条、软糖 | 三类仍可识别，动作数组为空，未恢复“先拿辣条、放糖果、取鸡肉、再放辣条”的复杂顺序。没有把人工初始库存写进提示词 |
| v8 | 瓶装饮品 | 仍识别为饮品；实际放入动作被模型标为move，说明add/move语义还不稳定 |

首轮部分品牌看似详细，不能都当作正确：背面文字补全、包装重叠和熟悉商品先验会让模型过度肯定。第二轮品牌必须出现在模型抄录的文字中才保留，identity_support最高保守为medium，仍会发生“把文字本身读错”。需要独立OCR/人工核实才能进一步提高可信度。

### 局部清晰度补测

最后仅对v8追加一次实验：对模型给出的每个物品区域计算清晰度/曝光、惩罚贴图像边缘的框，再选择最多3张crop。有效饮品主图比第二轮首先展示的入画模糊图完整清楚，仍只输出饮品大类，不强补品牌。模型又提出一个抽屉候选，crop复核将它拦截，说明背景过滤仍需保留。

此次动作却从上一轮move变为错误remove，进一步证明同一模型多次输出会波动、几何校验不能证明动作正确。该实验是主图排序的小范围验证，不算完整第三轮，也不证明算法已解决遮挡或精准分离。输出保留在`crop-rank-check`，没有覆盖前两轮。

## 6. 当前流程做了什么

1. PyAV按PTS解码；3fps扫描代理图，计算固定尺寸下的模糊、曝光、帧间变化。按时间分桶挑质量较好的代表帧，第二轮保留首尾锚点。
2. 对极相似代表帧做保守去重，保留首尾。合成静态视频测试确认能抑制冗余；这8段手持拍摄变化较大，第二轮实际没有触发近静态代表帧删除。原视频始终保留。
3. 多模态模型提出开放物品候选和0–1000归一化框；程序校验顺序、范围和帧引用，从原始1920×1080帧裁剪，保留3.5%边距。最新代码在模型候选视角内做局部清晰度排序；两轮结果仍保留旧顺序，额外v8验证新顺序。
4. 独立提示词复核crop、文字、品牌候选和定位质量；程序拦截背景、无来源引用及没有抄录文字支持的品牌/款式。
5. 原生function call调用本地只读词表检索，返回带来源ID的资料；仅规范大类，不用资料猜库存身份或日期。
6. 额外视觉调用提出动作候选；程序从真实帧计算事件时间窗，始终`committed=false`。绝对放入时间、生产日期和到期日均保持null。
7. 导出JSON、标框图、crop、音轨、HTML及完整调用审计。音轨未转写，未运行库存事务。

## 7. 下一步技术顺序

优先补定位和身份关联，单纯增加RAG或提示词长度不能解决混框。

1. **局部定位/分离**：给现有VLM提供带坐标网格的单帧定位，再与Grounding DINO开放词表候选比较；相邻包装用SAM 2.1分割辅助。评测人工框IoU、物品完整率、混入相邻物品率。遮挡区域无法凭算法恢复真实外观，mask也不等于库存身份。
2. **清晰crop排序与文字复核**：对每个物品区域单独算清晰度、遮挡和文字可读性，加入PaddleOCR及必要的旋转纠正。保留OCR原文/框，核对品牌和款式；条码可解码时查可靠产品库。当前全图清晰不代表小物品清晰。
3. **动作补帧**：对疑似进入/离开、手遮挡前后的区间加密至8–12fps，保留全片原始PTS；分别判断物品是否在柜内、是否移动、是否越过边界，再组装事件。v7应作为主要回归样本。
4. **跨帧身份**：跟踪器+外观/文字描述关联正背面，同款多件保持歧义集合；只对有证据的关联合并观察。固定K230视角建立ROI，减少手持相机运动造成的伪变化。
5. **音频**：加入faster-whisper或FunASR，保留音频相对共同原点的偏移；用户说出的品名作为独立来源，不能覆盖视觉冲突或凭空推出动作。
6. **商品RAG与图片检索**：添加用户核实的商品记录、可信网页来源和包装图，必要时用SigLIP/CLIP检索本地商品图候选，再用OCR/特征复核。当前只有6条大类定义，不是已建成商品库。
7. **独立评测**：再录未参与改进的视频，按完整会话划分留出集，单独评价大类、品牌、截图、实例关联和动作。对高/中/低证据分组核对后再校准数值置信度。
