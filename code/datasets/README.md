# 视频素材与标注

当前素材为根目录`data/v1.mp4`至`v10.mp4`及人工过程`data/ans.md`。v1-v8保留旧认物/动作回归；新增v9约10.38秒、v10约7.24秒，均含音轨，目前只完成关键帧和音轨预处理，尚无ASR/提醒验收结果。具体判断见[评测与失败经验](../doc/evaluation-and-lessons.md)。本目录`templates`仅是标注空模板/虚构填法示例，不计入真实评测。

## 素材规则

- 原视频保留音轨、原分辨率与原时间戳，不覆盖、不加字幕、不二次压缩。派生文件放`backend/var`，不提交Git。
- 每次录制使用独立capture_id，记录位置、设备和可信开始时刻；不知道绝对拍摄时间就null，不用文件复制日期或分析日期补全。
- 同文件的音视频使用共同时间原点；独立音轨记录audio_offset_ms，未知不填0。
- 人工答案只用于评测，不能输入识别提示词或商品词库。生产可知的初始库存单独标记和受控提供，不等于把整段答案喂给模型。

## 下一批录制

优先固定相机与光照，拍到抽屉内ROI和进出口；保留开门到位后首次交互前的稳定画面、全部操作过程、最后手退出后关门前的稳定画面。关门后若只能看到前板，该图不具备箱内结束状态。

覆盖单件存入/取出、手经过但未动、拿出后放回、多件同放/同取、翻面、同款两件、遮挡恢复，以及语音缺少年份/时间、多件指代、改口和取消。现有v1-v10已用于观察/设计，属于开发素材；之后未参与调参的新完整会话才作留出，不能随机把相邻帧分到训练/评测两侧。首版不做重量变化。

## 最小标注

| 内容 | 要求 |
| --- | --- |
| 初始/最终库存 | 用人工实例ID区分同款，未知与空柜不同；标可见性 |
| 净变化 | 新增/移除/保留/未知；与动作历史分开 |
| 动作历史 | add/remove/move/take_and_return/uncertain及尽量窄的媒体时间窗 |
| 代表帧 | 原图xyxy框，必要时mask；说明模糊、遮挡、正背面 |
| 字段 | 大类、可读文字、品牌款式；无法由画面观察的事实标observable=false |
| 稳定片段 | 操作前、每次手退出、操作后；标明ROI是否完整可比 |
| 语音 | 原音频PTS时间窗、人工语义及关键数字/单位/否定；标注“这个”对应实物或有歧义；不把答案输入ASR/语义模型 |
| 日期与提醒 | 原文、明确/缺失的年月日、期限单位、可信或显式测试时钟、期望任务/草稿及缺失项；定时与取出条件分开 |

已有模板可继续填写；字段仍未增加净变化/稳定片段时可先写在人工说明里，不伪装成已有结构化真值。运行命令见[后端说明](../backend/README.md)，无需先训练一套固定物品类别。

2026-10-17第一批已实际处理v9/v10，原始ASR及失败保留在`backend/var/runs/batch-a-asr`，推理结果和隔离库在`backend/var/experiments`。两者是开发样本，v7在暖库实验中只作另一会话的检索隔离检查，不算新物品留出准确率。真实音频只说出v10“吃掉”提醒；额外过期取出需求以显式产品策略记录，不能把ans.md说明伪装成语音转写。
