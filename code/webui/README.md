# Mind Box 界面预览

这一版用于确认界面和交互，独立于正在开发的后端。页面所有物品、设备、开合状态和提醒均为本地预览数据，不写正式数据库、不连接真实硬件、不调用影眸或语音 API。提醒的编辑和完成状态可预览，尚不执行定时送达。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的地址，默认是 http://127.0.0.1:5173/。端口占用时 Vite 自动选择下一个端口。

```sh
npm run build
npm run preview
```

这是模块化前端，需要通过开发服务器或构建后的静态服务打开。此前的单文件页面保存在 `prototype-v1.html`。

## 可以体验

- 右侧选择设备、添加预览设备、收起或展开面板。
- 浅色、深色、跟随系统三种外观选择；开关物品建议、减少动态效果。
- 物品搜索、按层筛选、修改名称/位置/日期/备注、标记取出。
- 添加、编辑、删除、完成预览提醒；支持一次和每日选项。
- 底部文字交互可查询预览物品，例如“充电线在哪”；涉及提醒时打开表单核对，缺少时间不会伪报创建成功。麦克风尚未接入。
- 主场景下方选择抽屉，右上角播放图标演示该抽屉开合。开合不代表能操纵真实柜体。
- 主场景右上角的包裹加号、减号分别演示当前层放入和取出。演示时先打开对应抽屉，再播放物品进入或离开的小段轨迹；短暂显示物品名称，件数、物品列表与最近记录同步更新。取出默认选择当前层最新的一件，空抽屉禁用取出。
- 概览的实时区域和设置中也有放入、取出演示入口。从物品详情标记取出时同样播放动画。
- 抽屉打开后，概览显示固定摄像头区域；没有视频源时显示未连接。放入演示可保留示例原话，没有调用摄像头或语音识别。

主动收起面板后，普通开合不强制展开。手机默认收起，点右上角图标查看面板。查询是用户主动操作，会展开并显示物品所在层，但不把已关闭的抽屉画成打开。

预览数据和偏好保存在浏览器 `mind-box-preview-v2` 键中，清除该站点数据可恢复初始样例。没有后台运行、提醒送达或数据库同步能力。

## 文件与后续接入

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面结构、无玻璃效果的双主题与响应式布局 |
| `app.js` | 独立预览数据、面板和表单交互 |
| `cabinet.js` | Three.js 简化柜体、三个独立抽屉、按需渲染 |

模型按商家照片的框架、三层和脚轮近似制作，未经过尺寸校准，也不是影眸生成结果。柜体约 1 万三角面，示例物品增加少量几何体；食品包装、瓶装物品和线材使用不同的简化外形，并非物品扫描模型。每层最多显示六个示意物品，实际预览件数仍以列表为准。

采用不透明材质与约 1.35 秒的平滑取放轨迹，无粒子、模糊或玻璃效果。停止操作与动画结束后不持续渲染，页面隐藏时暂停动画。减少动态效果的设置和系统偏好均会跳过运动、保留文字回执。动画中暂时禁用重复演示，设备切换会清除旧动画；数据变化来自预览操作，不依赖动画结束，不会因为取消动效丢失或重复记录。3D 单独加载，失败时保留其他面板与文字反馈。

以后先用后端设备快照和有序事件替换预览状态，再接视频、语音转写和正式库存回执。模型开合、物品候选、正式入库必须分别更新。真实后端契约以 `../doc/data-contract.md` 为准，这个原型没有新增正式接口。
