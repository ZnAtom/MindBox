# Mind Box 界面预览

这一版用于确认界面和交互，独立于正在开发的库存后端。物品、提醒及设备列表仍为本地预览数据，不写正式数据库、不调用影眸或语音 API。第一台柜体现可通过本地 USB 桥接接入 K230 按键产生的开合状态；提醒尚不执行定时送达。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的地址，默认是 http://127.0.0.1:5173/。端口占用时 Vite 自动选择下一个端口。

### K230 按键联动

从项目根目录运行 `python3 -u code/device/k230/pc_door_bridge.py`，在 VS Code CanMV 运行 `code/device/k230/k230_key_door.py`。IO21 KEY 连续按 1/2/3 次分别切换第一台柜体上/中/下层；松开后约 500 毫秒判定一组。摄像头持续输出 1280x720 图像，电脑持续接收并缓存最近十秒；第一台柜体有抽屉打开时，概览面板显示实时画面。

`vite.config.js` 将 `/api/doors` 和 `/api/camera` 代理到 `127.0.0.1:8765`，页面通过 SSE 接收完整门状态，通过 MJPEG 显示画面。页面刷新/重连自动同步，硬件在线时禁用对应柜体的演示开关。第二台柜体继续使用预览交互。桥接失联保留最后姿态并显示未连接，不把缓存帧当成实时画面。

修改桥接端口时设置 `MIND_BOX_BRIDGE_URL=http://127.0.0.1:<端口>` 再启动 Vite。`--simulate` 桥接模式只用于电脑测试，网页明确显示“模拟设备已连接”。后续真实门磁沿用相同三层快照协议。缓存接口、运行前提和故障处理见 [K230 接入说明](../device/k230/README.md)。当前只有内存滚动缓存，整段会话归档、音频、实时识别及正式库存仍待接入。

```sh
npm run build
npm run preview
```

这是模块化前端，需要通过开发服务器或构建后的静态服务打开。此前的单文件页面保存在 `prototype-v1.html`。

## 可以体验

- 右侧选择设备、添加预览设备、收起或展开面板。
- 浅色、深色、跟随系统三种外观选择；开关物品建议、减少动态效果。
- 物品搜索、按层筛选、修改名称/位置/日期/备注、标记取出。
- 添加、编辑、删除、完成预览提醒；支持一次和每日选项。
- 底部文字交互可查询预览物品，例如“充电线在哪”；涉及提醒时打开表单核对，缺少时间不会伪报创建成功。麦克风尚未接入。
- 主场景下方选择抽屉，右上角播放图标演示该抽屉开合。开合不代表能操纵真实柜体。
- 抽屉打开后，概览显示固定摄像头区域；没有视频源时显示未连接。旁边的添加物品图标可模拟一次放入，并保留示例原话。设置中也有演示控制。

主动收起面板后，普通开合不强制展开。手机默认收起，点右上角图标查看面板。查询是用户主动操作，会展开并显示物品所在层，但不把已关闭的抽屉画成打开。

预览数据和偏好保存在浏览器 `mind-box-preview-v2` 键中，清除该站点数据可恢复初始样例。门状态以在线板端快照为准；没有提醒送达或库存数据库同步能力。

## 文件与后续接入

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` | 页面结构、无玻璃效果的双主题与响应式布局 |
| `app.js` | 独立预览数据、面板和表单交互 |
| `cabinet.js` | Three.js 简化柜体、三个独立抽屉、按需渲染 |

模型按商家照片的框架、三层和脚轮近似制作，未经过尺寸校准，也不是影眸生成结果。整体约 1 万三角面，使用不透明材质；停止操作与动画结束后不持续渲染，页面隐藏时停止动画。3D 单独加载，失败时保留其他面板。

当前接入本地 K230 门状态和摄像头预览，尚未绑定正式后端设备身份。后续接会话视频、语音转写和库存回执。模型开合、物品候选、正式入库分别更新。正式后端契约以 `../doc/data-contract.md` 为准。
