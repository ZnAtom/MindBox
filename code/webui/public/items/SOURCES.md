# 样例图片来源

本目录图片取自项目自有测试视频，用于预览设备展示，不代表当前实时识别结果。

| 图片 | 内容与处理 |
| --- | --- |
| `cola.webp` | 罐装饮品，原始帧裁剪、轮廓遮罩及方向调整 |
| `chicken.webp` | 鸡胸肉包装，原始帧裁剪及轮廓遮罩 |
| `tea.webp` | 瓶装茶饮，原始帧裁剪、轮廓遮罩及方向调整 |
| `capture-v10.webp`、`capture-v8.webp` | 对应视频画面的缩小版本，用于查看样例记录 |

缩略图为 480 × 480 WebP，保留主体颜色与比例；记录画面宽 960 像素。原始本地视频不随仓库发布，页面只依赖本目录的图片。
