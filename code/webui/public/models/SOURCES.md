# AI 柜体资产来源

本目录模型来自本项目实际调用影眸 Hyper3D 的结果，不是原有 `cabinet.js` 参数化模型导出，也不是图片生成的效果图。

- `cabinet-v1.glb`：Rodin Gen-2.5-Medium，任务 `2836b229-a01e-4689-bee5-1648e65fdc35`。原始文件 `base.glb` 为 349,744 字节；本地统一材质后为 349,924 字节，9,532 个三角面。
- `cabinet-v1-split.glb`：Bang 文件上传模式，任务 `637c8915-2e14-4090-b523-76924447930c`。统一材质后为 483,992 字节，10,000 个三角面、8 个网格。结构未达到四组独立抽屉要求，不具备已经验证的抽屉运动配置。
- `reference-01-F.webp`、`reference-02-FR.webp`、`reference-03-FL.webp`、`reference-04-B.webp`：来自 `data/3d/360.mp4`，时间约 1.53、4.76、10.62、6.73 秒；校正手机旋转、裁剪柜体、手动标定背景遮罩并缩小为 WebP，供预览对照。

两份 GLB 保留 AI 输出几何，统一为一个中性、不透明、粗糙度 0.7 的材质；移除照片纹理引用与顶点颜色，不增加装饰。没有进行尺寸标定或把自动拆分结果改称正确的抽屉组件。预览采用 Y 轴旋转 -90° 对齐正面；仅改变显示朝向，不修改几何比例。

完整工作流与判断见 `code/modeling/README.md`、`code/modeling/RESULTS.md`。本目录不包含 API 密钥、任务订阅凭证或签名下载地址。
