# Mind Box：项目简述

更新：2026-10-13。总体构想原名“万物无感”，设备暂称 Mind Box。详细行动顺序见 [Roadmap](../discussion-roadmap.md)。

本次能力范围见 [产品形态草案](product-concept.md)：以无遮挡单件、小批量为基础，遮挡补全和时间回推列为加分项，可不做。

## 想解决什么

你已有多个零食收纳盒，但会忘记里面的东西，直到零食受潮、需要丢弃，或水果腐烂产生异味才注意到。也会忘记自己设定的日常计划。

当前候选用户：宿舍里会囤食品、确实因遗忘产生麻烦，又不愿额外登记和规划的人。首个场景仍待确定。

## 产品主张

> 将用户主动记忆物品，变成 Agent 帮用户记忆。

正常收纳时设备尽可能自动记录；用户需要时询问“还有什么”“有什么零食可选”，或接收有依据的提醒。

可以轻微调整收纳习惯，**不能强制增加日常登记操作**。用户主动补充、询问或设定提醒是可选服务，不是每件物品都要做的步骤。

## 候选能力

| 方向 | 想法 |
| --- | --- |
| 观察与记忆 | 自动记住物品、位置、时间、照片及进出变化 |
| 查询与提醒 | 查询库存、关注久放物品、记录用户主动交代的计划；未提供日期时保留未知 |
| 语音 | 自然语言查询、可选补充与提醒指令，不强制逐件对话 |
| 屏幕 | 展示库存、照片与相关提醒 |
| 历史观察 | 遮挡后随自然翻动补录、每日记录水果外观，均为待评估想法 |

未知信息不能编造；入库时间不等于生产或开封时间，估计的关注时间不等于真实有效期，拿出不等于吃掉。

## 已有调研

[第一次](../survey/1.md)直接受访者食物少、不需要；其室友是待访问的潜在线索。[第二次](../survey/2.md)没有报告严重损失，但接受固定位置、批量放入，拒绝逐件登记和自己决定吃完日期。

这些反馈支持减少操作与思考负担的方向，尚未证明普遍需求或实际省心程度。问卷见 [调研初稿](../dorm-survey.md)，可继续补访。

## 展示方向

从真实宿舍的遗忘、受潮、水果放坏等个人经历出发，展示实际产品，最后用短片表达一个具体未来场景。

候选巧思：放入苹果并随口交代“3 分钟后提醒我吃”，介绍过程中提醒响起，形成 Callback。不一定采用，若采用须真实执行任务。

## 长期愿景

成为现实物品与个人 AI 的信息入口，减少反复描述现实状态。未来可探索冰箱、药箱、宠物食品、化妆品、零售和办公物资，以及接口、购物清单、补货或周报。

上述扩展暂不纳入 48 小时承诺。跨场景、低成本、通用识别和持续准确库存都仍是假设；药品/食品状态判断、隐私与运行成本需要按实际范围考虑。

当前未确定外观与全部功能范围；实现讨论见 [技术讨论](../technical/technical-discussion.md)，用户已确认的技术信息见 [技术方案](../technical/technical-solution.md)。
